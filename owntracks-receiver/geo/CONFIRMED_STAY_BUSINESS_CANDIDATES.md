# 生活記録：本人確認済み滞在先からの店舗名候補（オフライン）

## できること

- すでに本人が訪問先を確認した記録（現状は月別シートの「滞在（GPS推定）」、備考に「訪問先は本人確認済み」を明記）を、同じ日付のOwnTracksの**GPS観測時刻**と突き合わせる。
- 本人が「許可した公開施設名」を**非共有の個別設定**から読む。自宅・利用者宅・支援対象者宅・仕事先の名称は許可一覧に入れない。GitHubにその一覧を置かない。
- GPS精度25m以内で、推定滞在時間帯の開始から2分後～終了2分前に重なる観測があるときに限り、既存「店舗名の修正」シート **D列「自動店舗候補」** を更新。異なる施設名の時間窓が重なるときは保留。
- 本人修正F列、元GPS・日時、月別の全既存行、住所候補E列と住所の出典N/O列は不変。P/Q列に「店舗名候補の根拠／判定日時」を保存し、Dの候補と住所の出典を混同しない。
- 「候補」は時刻一致からの**推測**。当該GPS座標が実店舗と一致したこと・実際の入退店・開始/終了時刻は確定しない。店舗名は間違い得るので黄色いF列で修正し、その修正を常に優先する。
- 出力は年別Excelの新しい**コピー**。データは外部API、公開CI、GitHubへ転送しない。元の年別Excelは上書きしない。保存する管理側は、既存正本とバックアップの版/権限/ハッシュ確認と再読み戻しが必要。

## 利用上の制限

この初期実装は「既存の本人確認済み訪問先があり、推定滞在時間との一致が分かる場合」のみ。すべての店舗を検索するAPIではない。OpenStreetMap/Geofabrikの店舗データから自動発見する方式とは別で、**追加の外部地図通信は0件**。

既存記録の11月15日は、酒はりの訪問先自体は本人確認済みで、17:03:51～18:53:00はGoogleマップ推定滞在時刻。OwnTracksの17:07の観測はその時間帯に含まれるので、**1件だけ「酒はり（しゅはり）」という未確認候補**を作成できる。位置一致や入店時刻が証明されたわけではない。

## 実装

`confirmed-stay-business-candidates.py` は `artifact_tool` を使った非公開ワークブック差分更新処理。ユーザーごとの公開施設名ホワイトリストを含むJSONは、DriveにもGitHubにも公開せず、作業時の非公開領域だけに置く。

```bash
python confirmed-stay-business-candidates.py \
  --source 生活記録_2026.xlsx \
  --output 未確認店舗候補_更新案.xlsx \
  --allowed-places-file /private/public_venues.json
python test-confirmed-stay-business-candidates.py
```
