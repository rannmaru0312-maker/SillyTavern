# MIYA & KOHARU 自動開発ルール

## 開発目標
利用者ごとに最適化されるパーソナルAIアプリを開発する。

## 優先機能
1. 利用者別・キャラクター別の長期記憶
2. 会話からの自動記憶候補抽出
3. 記憶の検索と会話への反映
4. ネット検索と画像生成
5. 音声会話と秘書機能
6. 認証、課金、AI利用量管理

## 必須ルール
- 本番環境 ~/miya-koharu を自動変更しない。
- 本番の会話履歴、キャラクターデータ、記憶データを変更しない。
- 開発作業は ~/miya-koharu-dev 内に限定する。
- 記憶候補は承認前に長期記憶へ保存しない。
- 利用者別・キャラクター別のデータ分離を守る。
- 承認待ち候補は最大100件とし、勝手に削除しない。
- 認証情報や個人情報をGitHubへ送信しない。
- 大容量処理や複数の並列テストを避ける。
- 本番反映と外部公開は利用者の承認を必要とする。
- 変更内容、テスト結果、未解決事項を記録する。

## 自動開発の基本手順
仕様確認 → 開発計画 → コード変更 → テスト → 結果報告 → 承認
