# Instructions for coding agents working under docs/social/

This directory is a **public, documentation-only coordination sandbox** for planning organic social content. It is NOT the application runtime, and the documents here do not grant access to or control of Instagram, Threads, Metricool, or any Codex cloud session.

## Non-negotiable
- Work only under `docs/social/` on a separate branch/PR. Do not modify application code, user memory, auth, billing, API clients, CI, actions, or deployment configuration.
- This repository is PUBLIC. Do not write credentials, tokens, private analytics exports, personal information, private messages, internal URLs, unpublished reference image files, or unpublished application specifics.
- No external paid services, new API credentials, follows/unfollows, unsolicited comments/DMs, follower purchases, or automated posting.
- Never present suggested posts as actually scheduled or published. Scheduling/publishing belongs to a separate explicitly authorized workflow which checks real-time account linkage and duplicate posts.
- Preserve the approved two-per-week cadence (Tuesday/Friday 19:00 Asia/Tokyo). Treat 2026-11-10 at 19:00 as already reserved (subject to independent confirmation), so do not propose a duplicate.
- Do not promote the app before its owner's explicit publication approval.
- Do not claim direct Codex session handshakes or automatic sync without observing a Codex-authored reply.
- Images: use the approved character reference if available through the authorized image workflow; never use generic stand-in portraits. For selfie-style interiors, show roughly half the character's face at a frame edge with 60–70% or more of the image dedicated to the room/setting. Seasonal styling, realistic casual smartphone photography, natural scene variety. No source images are stored here.
- Captions: Japanese, warm natural Kansai dialect, original practical interior tips. Keep hashtags brief and relevant, no hashtags containing `AI`. AI-generated disclosures must be made on the publishing platform as required; do not represent fictional outings as actual visits.
- The optional drinking topic is roughly monthly; if used, include `#飲みとも募集してます`, never imply real-life meetings or promote excessive drinking.
