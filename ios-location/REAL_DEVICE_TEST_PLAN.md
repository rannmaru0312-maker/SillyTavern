## 2. Mac + Xcodeでの端末インストール（事前許可後）

1. macOSのXcodeとXcodeGenの対応する版を準備し、GitHubの該当PRブランチを取得する。
2. `cd ios-location && xcodegen generate` を実行する。
3. `ios-location/MIYALocation.xcodeproj` をXcodeで開く。
4. `MIYALocation` ターゲットで利用者が承認したApple開発用Team・一意のテスト用Bundle IDを設定し、物理iPhoneを選ぶ。
5. 署名・プロビジョニングの条件を本人が確認した後でDebugビルドをインストールする。失敗時は追加契約せず原因を記録する。
6. iOSが要求する位置情報の利用目的を確認し、実験に同意する場合だけ許可する。

## 3. 位置情報の段階検証

- 位置情報が「許可しない」「App使用中のみ」「常に許可」のそれぞれの場合の画面・監視開始結果を確認する。
- 実際の個人宅・勤務先ではなく、本人が承諾した**架空名のテスト地点**のみを登録する。GPS座標と滞在事実はGitHubにアップロードしない。
- 監視開始・アプリの停止・再起動・画面ロック・機内モード・権限取り消しで、検知の可否と遅延を確認する。
- 到着と退出は建物内への出入りではなくジオフェンス境界の**推定検知**であると表示し、本人が日時を修正する手順を確認する。
- 日付をまたぐ訂正、記録ファイルの読み込み失敗、端末の再起動後の再開を確認する。未検証のケースはチェック完了と報告しない。
- バッテリー使用量・アクセス頻度・位置情報アイコンの挙動を確認し、懸念がある場合は監視を停止する。

## 4. 7日分・外部フォルダー連携の段階検証

1. まず個人情報を含まない**テスト環境とテストイベント**だけを使い、端末内の週次保存・SHA-256照合・JSON書き出しを確認する。
