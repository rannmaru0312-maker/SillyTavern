# MIYA Location — 個人利用MVPの優先順位（2026-11-15）

## 現時点の利用者
当面は開発者本人の個人利用のみ。将来のMIYA & KOHARU一般公開・多人数対応は別フェーズであり、今回のGPS生活記録アプリの導入前提にはしない。

## 最優先（個人利用で本当に使えること）
1. iPhone実機に署名済みの開発用アプリをインストールし、本人許可のもとでジオフェンス到着/退出と位置権限の挙動を検証する。
2. 端末内の記録、日時訂正、週次JSON/CSV保管と復元を実機で確認する。GPSは推定であり、建物への入退店を保証しない。
3. 本人選択のiOS Files保存先（Google Driveを含み得る）へ、任意許可でバックアップを送る。クラウドに実際に届いたかはGoogle Drive側から別途読み戻して確認する。
4. 現在の生活記録スプレッドシートへの7日分取り込みは、ハッシュ・イベントID・重複・時刻訂正・本人手入力との競合を検証し、書込み後の行読み戻しが全件一致したときだけ「保存完了」と報告する。
5. 通信不可・保存失敗・権限拒否・バックアップ欠損時も元データを上書き・消失させない。

## 維持する安全境界
- 既存のサーバー認証・利用者分離を壊さない。将来拡張用コードはそのまま残してよいが、個人用MVPの必須経路にはしない。
- 現状のサーバー訪問記録APIは既定無効のまま。Render無料Webサービスの揮発可能なストレージを正本扱いしない。
- iPhoneからのDriveへの直接API自動送信、Google Driveクラウド反映とSheetsへの取り込みは**まだ実機のE2E検証がない**。完成済みとは報告しない。
- 追加費用、新規課金、Apple署名や実機への配布、本番デプロイ、実個人記録の外部送信、共有権限変更は本人確認なしに実行しない。
- 今の開発PR #29はDraftのまま。将来の多人数化に備えた安全なデータ形式、イベントID、本人確認・プライバシーの考え方を維持する。

## 個人利用の合格条件（実機確認）
- iPhoneから仮のテスト地点の検知・記録・訂正まで完了
- 検証済み週次ファイルを本人の選択先へ保存し、外部のGoogle Drive接続から同じバイトを読み戻せる
- 7日分のレコードが既存生活記録に重複なく保存され、Sheet再読取で一致する
- 削除・復元・権限失効・通信失敗への対処を検証し、記録の保全を確認する
